# Schola Mimic

Schola Mimic is a small learning implementation of the core Schola architecture.
It connects an Unreal Engine environment to Python reinforcement-learning code.

The project is intentionally incomplete. Its first milestone only verifies that:

- the standalone Unreal project builds;
- the `ScholaMimic` runtime plugin loads;
- the `schola_mimic` Python package installs and imports.

Development rationale and architecture decisions live in the repository-level
`docs/` directory. User-facing instructions live in this directory's `docs/`.

See [Getting Started](docs/getting-started.md).
